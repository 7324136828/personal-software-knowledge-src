## Least Squares Regression Plane
### Fitting several explanatory variables

- \(y=b_{0}+b_{1}x_{1}+\cdots+b_{k}x_{k}\)
- Plane in \(k+1\) dimensions
- Squared residual minimization
- \(\widehat{y}=b_{0}+b_{1}x_{1}+\cdots+b_{k}x_{k}\)
- Term life fitted plane

**Speaker Notes:** Because a single plane usually cannot pass through all observations, least squares selects coefficients that minimize the sum of squared vertical deviations. For term life insurance, the fitted model is \(\widehat{y}=2.584+0.206x_{1}+0.306x_{2}+0.494x_{3}\).

**Sources:** Regression Modeling with Actuarial and Financial Applications_014 - 3 Multiple Linear Regression - I.tex

## Matrix Formulation
### Normal equations and coefficient estimator

- Response vector \(\mathbf{y}\)
- Design matrix \(\mathbf{X}\)
- Normal equations \(\mathbf{X}'\mathbf{X}\mathbf{b}=\mathbf{X}'\mathbf{y}\)
- \(\mathbf{b}=(\mathbf{X}'\mathbf{X})^{-1}\mathbf{X}'\mathbf{y}\)
- Invertibility without linear dependence

**Speaker Notes:** Matrix notation makes the least-squares solution compact and scalable. A unique formula requires that the explanatory variables not be linear combinations of one another, so that \(\mathbf{X}'\mathbf{X}\) is invertible.

**Sources:** Regression Modeling with Actuarial and Financial Applications_014 - 3 Multiple Linear Regression - I.tex

## Regression Function and Assumptions
### Interpretation and sampling framework

- \(\mathrm{E}y=\beta_{0}+\beta_{1}x_{1}+\cdots+\beta_{k}x_{k}\)
- Linearity in parameters
- Other variables held fixed
- Constant variance \(\sigma^{2}\)
- Independent normal responses or errors

**Speaker Notes:** For a continuous explanatory variable, \(\beta_j\) is the expected change in the response per unit change in \(x_j\), holding the other explanatory variables fixed. The model may be nonlinear in explanatory variables while remaining linear in its parameters.

**Sources:** Regression Modeling with Actuarial and Financial Applications_014 - 3 Multiple Linear Regression - I.tex

## Properties of Least Squares Estimators
### Precision and distribution

- Unbiasedness: \(\mathrm{E}\mathbf{b}=\boldsymbol{\beta}\)
- Variance: \(\mathrm{Var}\mathbf{b}=\sigma^{2}(\mathbf{X}'\mathbf{X})^{-1}\)
- Normality under F1–F5
- Gauss-Markov minimum variance
- Linear unbiased estimators

**Speaker Notes:** Under assumptions F1 through F4, least squares coefficients are unbiased and have the stated covariance matrix. With normal responses or errors, the coefficient vector is normally distributed, supporting later statistical inference.

**Sources:** Regression Modeling with Actuarial and Financial Applications_014 - 3 Multiple Linear Regression - I.tex

## Goodness of Fit
### Residual variation and explained variation

- Residuals: \(e_i=y_i-\widehat{y}_i\)
- \(s^{2}=\frac{\sum e_i^{2}}{n-(k+1)}\)
- Total SS = Error SS + Regression SS
- \(R^{2}=\frac{\mathrm{Regression\ SS}}{\mathrm{Total\ SS}}\)
- Adjusted \(R_a^{2}\)

**Speaker Notes:** The residual standard deviation is the typical error about the fitted regression plane. While \(R^2\) is the proportion of response variability explained by the regression, it never decreases when a variable is added; adjusted \(R^2\) accounts for degrees of freedom.

**Sources:** Regression Modeling with Actuarial and Financial Applications_014 - 3 Multiple Linear Regression - I.tex

## Inference and Added Variable Plots
### Assessing one explanatory variable

- \(H_{0}:\beta_{j}=0\)
- \(t(b_j)=b_j/se(b_j)\)
- Degrees of freedom: \(n-(k+1)\)
- Added variable residual plots
- Partial correlation coefficients

**Speaker Notes:** The t-ratio measures how many estimated standard errors a coefficient is from zero; as a rule of thumb, an absolute t-ratio exceeding two indicates an important variable. Added variable plots compare residualized response and residualized predictor values, revealing the relationship after controlling for the remaining predictors.

## Special Explanatory Variables
### Flexible models within linear regression

- Binary indicator variables
- Polynomial transformations
- Logarithmic transformations
- Interaction terms
- Piecewise linear regression

**Speaker Notes:** Binary variables represent group differences relative to a base category. Transformations and interactions permit nonlinear response patterns and slopes that depend on other explanatory variables, while the model remains linear in the coefficients.

### Multiple linear regression foundations

- Joint effects beyond pairwise correlations
- Least squares regression plane
