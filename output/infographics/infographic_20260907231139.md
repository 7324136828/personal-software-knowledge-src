## Panel 2: The Normal Curve
### Fitting the Normal Curve
1. Collect data (e.g. MA bodily injury claims, n=272)
2. Compute mean, median, standard deviation, percentiles
3. Fit normal curve using ybar for mu and s_y^2 for sigma^2
4. Diagnose fit with histogram, box plot, and qq plot

## Panel 3: Power Transforms

### Box-Cox Family
1. lambda = 1: no transform
2. lambda = 1/2: square root
3. lambda = 0: natural log ln(y)
4. lambda = -1: negative reciprocal

## Panel 4: Sampling & Design
### Four Basic Sampling Assumptions
1. E(y_i) = mu
2. Var(y_i) = sigma^2
3. {y_i} independent
4. {y_i} normally distributed

### Designed vs Observational Data
1. RAND Health Insurance Experiment vs Galton height data
2. Analyst controls treatment vs Analyst cannot control assignment
3. Causal inference possible vs Statistical control only, confounders possible
